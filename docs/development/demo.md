# README terminal recording

[`terminal-demo.gif`](https://raw.githubusercontent.com/zz990099/Rigyard/debdb953f73736264fae1d940b31f629f1995948/assets/terminal-demo.gif)
is a three-second recording of the real Rigyard CLI. The first second shows `rigyard` being entered
in a terminal; the remaining two seconds show the resulting interactive menu. Recording the menu
does not start Docker containers or tmux sessions.

## README images

The README references the GIF and PNG with immutable raw GitHub URLs so they render on both GitHub
and PyPI. The vector logo source and its PNG export are archived at commit `debdb953`.
